## Tips for Using These Prompts

### In Midjourney
- Add `--style raw` for less interpretation
- Add `--v 6` or `--niji 6` for anime-style pixel art
- Use `--ar 4:3` for GBA screen proportions
- Try `--chaos 0` for more consistent results

### In Stable Diffusion
- Use specialized pixel art models or LoRAs
- Recommended: SDXL + PixelArt LoRA
- Sampling steps: 20-30
- CFG Scale: 7-9
- Sampler: Euler or DPM++

### In DALL-E
- These prompts work well as-is
- May need to emphasize "no blur, sharp pixels" more
- Request multiple variations

### In Flux (FAL.ai - Current Setup)
- Model: `fal-ai/flux/schnell` (fast, 1-4 steps)
- For better quality: use `fal-ai/flux/dev` (8-12 steps)
- Post-process with pixelization (scale 4-6x)

### For Minimax Video (Animated Backgrounds)
Example motion prompts:
- **Clouds:** "gentle clouds drifting slowly left, subtle wind motion, looping animation"
- **Water:** "water flowing right to left, gentle ripples, seamless loop"
- **Stars:** "twinkling stars, subtle shimmer, peaceful night sky"
- **Particles:** "floating particles drifting upward, gentle motion, ambient atmosphere"

## Asset Dimensions

- **Sky:** 1024×768 (landscape, full background)
- **Layers (far/mid/near):** 1536×512 (wide banner)
- **Posters:** 768×1024 (portrait, 3:4 ratio)
- **Title Card:** 1280×768 (landscape)
- **Hero Sprite Frame:** 768×1024 (portrait, single character)

## Pixel Scale

All assets use `pixelScale: 4` in post-processing:
- Image is downsampled to 1/4 size with nearest-neighbor
- Then upsampled back to original size with nearest-neighbor
- This creates the chunky pixel art effect

For more pronounced pixels, increase to `pixelScale: 5` or `6`.

## Generation Workflow

1. **Test prompts** in your preferred tool (Midjourney, DALL-E, etc.)
2. **Download best results**
3. **Run through pixelization** (optional if tool outputs pixel art natively)
4. **Place in `/public/game/` directories**
5. **Update paths** in `src/game/journey.ts` if needed

Or use the built-in generation:
```bash
npm run art:gen              # generate all missing
npm run art:gen -- --force   # regenerate everything
npm run art:gen -- --only=origin,grp  # selective regeneration
```
